# 🎃 Halloween Visitor Dashboard

## 📌 Project Overview

A Tableau dashboard designed to analyze **Halloween visitor trends across different years and time intervals**. The dashboard uses a Halloween-themed design to present visitor patterns in an interactive and easy-to-understand way.

## 📊 Dataset

The dataset contains visitor counts recorded at different times during Halloween evening.

* **Years:** Multiple years
* **Time:** 6:00 PM – 8:15 PM
* **Main Fields:** Year, Time, Visitor Count, Total Visitors
* **Dataset:** Halloween Visitor Data

## 🔄 Project Process

1. Loaded and prepared the dataset in Tableau.
2. Pivoted time-based columns into **Time** and **Visitor** fields.
3. Analyzed visitor activity across different time intervals.
4. Compared visitor trends and totals across years.
5. Created an interactive Halloween-themed dashboard.

## 📈 Key Insights

* Compared visitor trends across different years.
* Identified changes in visitor activity throughout the evening.
* Analyzed peak visitor periods.
* Compared total visitors across years.

## 🎨 Dashboard Features

* Halloween-themed design 🎃
* Time-based visitor analysis
* Year-wise comparison
* Interactive Tableau visualizations
* Simple and engaging presentation
