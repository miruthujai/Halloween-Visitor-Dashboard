# 🎃 Halloween Visitor Dashboard - Analyzing Halloween Visitor Trends

## 📌 Project Overview

This project focuses on analyzing and visualizing **Halloween visitor trends across different years and time intervals** using Tableau.

The dashboard was designed with a Halloween-themed visual style to make the analysis more engaging while presenting visitor patterns in a simple and interactive way.

---

## 📊 What is This Project About?

In this project, I worked with a Halloween visitor dataset containing visitor counts recorded at different times during the evening.

The main objective was to analyze how visitor activity changes throughout Halloween evening and compare the visitor trends across different years.

---

## 📁 About the Dataset

| Property    | Details                |
| ----------- | ---------------------- |
| Dataset     | Halloween Visitor Data |
| Data Type   | Visitor Count          |
| Years       | Multiple years         |
| Time Period | 6:00 PM – 8:15 PM      |
| Tool Used   | Tableau                |

### Column Details

1. **Year** - Year in which the Halloween visitor data was recorded
2. **6 PM** - Number of visitors recorded at 6:00 PM
3. **6:30 PM** - Number of visitors recorded at 6:30 PM
4. **7 PM** - Number of visitors recorded at 7:00 PM
5. **7:30 PM** - Number of visitors recorded at 7:30 PM
6. **8 PM** - Number of visitors recorded at 8:00 PM
7. **Total (8:15 PM)** - Total visitor count recorded up to 8:15 PM

## 📊 Steps I Performed

### Step 1 - Data Preparation

* Loaded the Halloween visitor dataset into Tableau
* Checked the available fields and data types
* Prepared the time-based visitor data for analysis

### Step 2 - Data Transformation

* Pivoted the different time columns into a single **Time** field
* Created a corresponding **Visitor** measure
* Organized the data for time-based analysis

### Step 3 - Visitor Trend Analysis

Analyzed visitor counts across:

* 6:00 PM
* 6:30 PM
* 7:00 PM
* 7:30 PM
* 8:00 PM
* 8:15 PM Total

### Step 4 - Year-wise Analysis

* Compared visitor activity across different years
* Identified changes in Halloween visitor patterns
* Examined the total visitor count for each year

### Step 5 - Dashboard Development

Created an interactive Halloween-themed Tableau dashboard to present the analysis in a visually engaging format.

## 📈 Key Analysis
